# Contributing

Look for issues labeled **good first issue**. Comment on an issue if you plan to work on it so others can coordinate with you.

1. Fork the repository and branch from `main`.
2. Set up JDK 21 and Android SDK 34 using the README.
3. Keep the change scoped to one issue. Run `./build.sh` for changes to the launcher.
4. Open a pull request with the change, how you checked it, and a link to the issue.

A TV is optional for documentation and JVM test changes. For device reports, include the model, Android version, and what you observed. Remove IP addresses, account information, and debugging credentials from logs and screenshots.
